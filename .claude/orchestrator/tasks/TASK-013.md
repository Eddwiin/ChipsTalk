Objectif:
Vérifier que frontend et backend utilisent correctement le même contrat API.

À vérifier:
- endpoints
- méthodes HTTP
- paramètres
- structures JSON
- types
- erreurs
- WebSocket

Critères:
- Aucun mismatch frontend/backend.
- Aucun endpoint utilisé par le frontend qui n'existe pas.
- Aucun champ attendu par le frontend absent du backend.
